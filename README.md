アブダビLP(`abu-dhabi-cosmic-consciousness-site/app/new`)の書体・色・余白・現れ方を引き継ぎ、

## ファイル

- `index.html` — 本文と構成(セクションごとにコメントあり)
- `css/style.css` — デザイン一式(冒頭に色の定義)
- `js/main.js` — スクロールで現れる動き/宇宙セクションの紺のヴェール
- `images/` — 写真・手書き素材(公式サイト sekinoayako.art とアブダビLPから)
